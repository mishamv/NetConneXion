# NetConneXion

NetConneXion — настольное приложение для Windows, объединяющее управление сетевыми профилями, работу с Wi‑Fi и набор инструментов сетевой диагностики.

## Возможности

### Сетевые профили

- Создание, копирование, редактирование и удаление профилей IPv4.
- Настройка DHCP или статических параметров IP, маски, шлюза и DNS.
- Применение профиля к выбранному сетевому адаптеру.
- Импорт и экспорт профилей в JSON.

### Wi‑Fi

- Поиск видимых беспроводных сетей.
- Отображение SSID, BSSID, уровня сигнала, канала, частоты, скорости и типа защиты.
- Подключение к выбранной сети из списка видимых сетей.
- Сохранение данных сети в профилях приложения.
- Просмотр сохранённых в Windows Wi‑Fi‑профилей.

### Сетевые инструменты

- Ping и Traceroute.
- DNS Lookup с системным DNS-сервером по умолчанию и возможностью указать другой сервер вручную.
- HTTP Check и проверка SSL-сертификатов.
- Просмотр сетевых адаптеров, Netstat, ARP и таблицы маршрутизации.
- Монитор сигнала Wi‑Fi и список видимых сетей.
- Сканер TCP-портов и просмотр кэша DNS Windows.
- Калькулятор IPv4-подсетей.
- Пакетная проверка IP-адресов из CSV/XLSX с фильтрацией и экспортом результатов.

### Интерфейс

- Светлая и тёмная темы.
- Русский и английский языки.
- Настройки запуска вместе с Windows и поведения системного трея.

## Системные требования

- Windows 10 или Windows 11.
- Python 3.10 или новее — только при запуске из исходного кода.
- Права администратора требуются для отдельных операций, изменяющих сетевые настройки Windows.

Основные зависимости:

| Пакет | Версия |
|---|---|
| PySide6 | `>=6.7,<7.0` |
| pywin32 | `>=306` |
| keyring | `>=25.1` |
| openpyxl | `>=3.1.2` |
| typing_extensions | `>=4.9` |

## Установка из исходного кода

```powershell
git clone https://github.com/mishamv/NetConneXion.git
cd NetConneXion
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python -m quickip
```

Для операций, изменяющих параметры сетевого адаптера, при необходимости запустите терминал от имени администратора.

## Хранение данных

- В обычном режиме пользовательские данные сохраняются в `%PROGRAMDATA%\NetConneXion`.
- В переносном режиме создайте файл `portable.flag` рядом с исполняемым файлом — данные будут храниться в расположенной рядом папке `data`.
- Секреты Wi‑Fi защищаются средствами Windows DPAPI; системное хранилище учётных данных используется как резервный вариант.

## Структура проекта

```text
NetConneXion/
├── quickip/
│   ├── app/             # запуск и сборка приложения
│   ├── core/            # конфигурация, хранилища и безопасность
│   ├── domain/          # модели предметной области
│   ├── events/          # события приложения
│   ├── features/        # профили, Wi-Fi и сетевые инструменты
│   ├── infrastructure/  # интеграция с Windows и запуск процессов
│   ├── shared/          # общие утилиты и пути
│   └── ui_qt/           # интерфейс PySide6, темы и виджеты
├── data/                # локализации и ресурсы интерфейса
├── tests/               # автоматические тесты
├── requirements.txt
└── NetConneXion.spec
```

## Сборка EXE

Установите PyInstaller и запустите сборку:

```powershell
python -m pip install pyinstaller
python -m PyInstaller NetConneXion.spec --clean --noconfirm
```

Готовый файл появится в папке `dist`.

## Безопасность

- Пароли Wi‑Fi не сохраняются в открытом виде.
- Команды Windows запускаются без передачи пользовательского ввода через командную оболочку.
- Перед импортом профилей проверяется структура входных данных.
